아이디 양식

|   |
| - |

사용자 아이디는 공백이 포함될 수 없으며 30자이내 알파벳 언더스코어 ( \_ ) , 숫자만

| - |

N-004

|   |
| - |

비밀번호 양식

|   |
| - |

비밀번호를 제외한 나머지 개인정보에는 특수문자가 들어갈 수 없다.

|   |
